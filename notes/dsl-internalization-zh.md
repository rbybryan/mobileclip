## §1. DSL 是什么,为什么端上用不了

仓库的两个评测口径(`tasks_clip/retrieval_utils.py:154-155`):

- **raw**(`ret_test_emb/`):直接用余弦相似度矩阵 `S`(1000 查询 × 1000 视频)排序。
- **DSL**(`ret_test/`):`S' = S * S.softmax(dim=0)` —— 每个视频先在**全体查询轴**上
  softmax,再乘回原分。效果:压掉「hub 视频」—— 那些对**很多**查询都给高分的嵌入。
  一个视频只有当它对**这个**查询的分显著高于它对**其他**查询的分时,才保得住排名。

这是 hubness(高维检索的中心化伪影)的一种事后矫正(CAMoE 的 dual-softmax;近亲:
QB-Norm CVPR'22、DBNorm)。**实测:raw↔DSL 差稳定 ≈ +0.7 r_mean,全部已测臂一致。**

**部署问题**:`softmax(dim=0)` 要**整个查询集**同时在场 —— transductive。端上单查询
检索(一条文本进来、查预建索引)拿不到「其他查询」,所以**部署数字只能是 raw**。
那 +0.7 现在是白白留在桌上的。

## §2. 内化 = 让 raw 分数自带 DSL 修完之后的性质

训练时把「hub 抑制」直接写进嵌入几何,使 raw 排序 ≈ 现在的 DSL 排序。
+0.7 是可回收上限。两个终点,**主终点选功效更高的那个**:

1. **主终点 · 差距闭合**:本臂自己的 (DSL − raw) 相比 r0 的 (DSL − raw) 是否显著缩小
   (配对,同 1000 查询)。内化成功的直接证据,且对臂的绝对水平不敏感。
2. **副终点 · raw 非劣**:raw 口径对 r0 非劣(内化不许把绝对精度赔进去)。

## §3. 怎么做 —— 三步阶梯,免费的先走

### 第 0 步 · 零训练闸门(分钟级,决定要不要训练)

用已有评测嵌入(或重导一次,分钟级)离线做两件事,**不碰训练**:

- **量 hubness**:每个视频对全体查询的平均相似度分布、k-occurrence 偏度。
  偏度小 ⇒ 没多少 hub 可修,+0.7 另有来源,整条线降级。
- **可部署基线:索引期矫正**。QB-Norm 思路,但归一化population换成**训练字幕库**
  (建索引时算好每个视频的先验分,单查询时只做减法 —— 端上合法)。
  它能白拿回 +0.7 的多少?
  - **大部分 ⇒ 不用训练**,当索引技巧出货(工程赢,零风险);
  - **小部分 ⇒ 训练臂才有立论**(说明 hub 性质要在嵌入几何里改,事后修不动)。

脚本 ~50 行,Claude 写(回「写吧」)。

### 第 1 步 · 损失(~20-30 行)+ 前置坑

批内自蒸馏:每步在 B×B 相似度矩阵上算 DSL 修正版(**detach 当 target**),
KL 把 raw 分布拉向它:

```
S    = 批内 t2v 相似度 (B×B)
S_t  = (S * S.softmax(dim=0)).detach()          # 批内 DSL target,不回传
L    = KL( softmax(S/τ) ‖ softmax(S_t/τ) )      # 两个方向 t2v/v2t 各一项
loss = vtc + λ_dsl · L                           # λ_dsl 预注册,如 0.5
```

批 512 的「查询群体」是测试 gallery 统计的代理。备选消融:Wang-Isola 均匀性正则
(只推嵌入分布,不用 DSL target)。

🔴 **前置**:先修 `loss_weight` 只是日志开关那个坑(round2 §5 P2,`tasks_clip/pretrain.py:114`
无权重求和)—— 与 KD 接线共享同一个前置,修一次两条线受益。

### 第 2 步 · 10k 冒烟门

λ_dsl=0 必须 bitwise 等于 r0;λ_dsl>0 时 KL 项有限且下降、批内列-softmax 熵上升
(hub 被压的直接征兆)。

### 第 3 步 · 1M 臂 `sub1m_dslint_s42`(15 h)

判读按 §2 的两个终点,配对 bootstrap,两口径都报。
**杀**:差距不闭合(主终点 NS)或 raw 显著劣于 r0 —— 两者任一即关线,不调 λ 续命
(1M 层不给刷超参的面,§11.2 同款纪律)。

## §4. 排期条件(诚实的)

- ⚠️ **+0.7 < δ=2.5** ⇒ 副终点在单基准上读不出来;主终点(差距闭合)是差中之差,
  CI 也不宽裕。**多基准面(v100 §8 第 3 步)恢复之后再排**,或明确接受
  「主终点 + 方向性副终点」的降级读法。
- 第 0 步不依赖任何前置,**现在就能跑** —— 它可能直接把这条线变成零训练的工程出货。

**新颖性定位**:测试期矫正(DSL/QB-Norm/DBNorm)是成熟家族;贡献点是
**为端上单查询把 gallery 侧归一化内化进权重**,加上「索引期矫正 vs 训练内化」的
干净对照 —— 部署导向,论文里放效率章,不冒充精度突破。

## §5. 可发表性判定(2026-08-03,对齐 `publishability-assessment.md`)

**单独发表:不行。** 三个理由:① 家族成熟 —— QB-Norm(CVPR'22)就是「可部署的
测试期矫正」,与本稿第 0 步基线几乎同物,20 行正则追 +0.7 在任何主会都会被评
incremental;② 第 0 步基线自带杀招 —— 若索引期矫正就能拿回大半,审稿人一句
「为什么要训练」就终结它;③ +0.7 低于本仓自己的噪声地板,一个连自家仪器都
读不出的主张不成其为主张。

**合法形态是三种**:① 论文部署/效率章的**一段+一张表** —— 本领域大量论文引用
DSL 口径抬分,一篇移动端论文明确报「可部署 raw 口径 + 我们把 transductive 差距
关掉了 Y%」是**可信度差异化**,不是新颖性主张;② 若第 0 步显示索引期修不动、
训练才修得动 ⇒「hubness 长在几何里」这个对照是可引用的发现(workshop 级);
③ 不管训不训,索引期技巧当工程出货。

**与论文主柱的关系**:`publishability-assessment.md` §1 判定全文只有一根柱子
(C2 弹性 T),其余都是支撑。DSL 内化是**装饰**(便宜、好看的装饰)。
真正推动 go/no-go 清单的是 §11.7-1 的**低 T 蒸馏** —— 它直接喂 C2 的
低预算 Pareto 点,而那张 Pareto 表按 §2 的原话「就是论文本身」。
创新预算该先花在那里。
