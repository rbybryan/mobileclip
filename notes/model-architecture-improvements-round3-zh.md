## §2 核查后改写的四条(C1 / C2 / C3 / C6)

### C1'(改写)· 把 stage-4 联合注意力蒸馏成**可分离**结构,推理期尽量无 softmax
- **为何改**:草稿说"蒸馏进时序卷积分支"在数学上不成立——联合注意力(`:529`)让 (t,h,w) 注意任意 (t′,h′,w′),而时序 Conv1d 只沿时间、逐空间位置混合(`:728-731`),**跨空间的那部分混合无法进入时序卷积**。
- **正确机制(两档)**:
  - **C1a(先做,低风险)**:训练期保留联合注意力作教师,推理期换成**逐帧空间注意力(固定 64-token softmax,静态形状可导出)+ 现有时序 Conv1d**,用特征匹配损失对齐。这**就是 P9「分离式时空注意力」**,用蒸馏来无损切换——**因此不能再宣称"严格超越 P9",它=可导出地实现 P9**。
  - **C1b(赌注,高风险)**:进一步把逐帧空间 softmax 也蒸馏进空间卷积 → **推理期彻底无注意力**。**这才是相对 P9 的真正增量**,但线性算子逼近内容相关空间注意力,时序/空间难样本预期掉 0.5–1.5 R@1;失败就回落 C1a 或 C4。
- **价值**:~~C1a 直接产出 whitespace §0 点名的首要缺失物——时序模型的端侧导出~~ ⚠️ **2026-07-28 作废**
  (§0-bis:U1 实测 ONNX + Core ML 全 pass,那个"缺失物"不存在)。**剩余价值只有峰值显存 + 一点 FLOPs**,
  却仍要付一整套蒸馏工程与掉点风险 ⇒ **从「本轮最高价值一步」降为条件项,由 TFLite 补测与真机延迟触发。**
- **锚点**:TimeSformer 分离式消融(支持不掉点)、attention→conv 蒸馏、FastViT 重参数化。

### C2'(改写)· 早期时序收缩,**但先把帧数改成逐阶段状态**
- **为何改**:`set_num_frames` 是**全局单值、forward 只设一次**(`:1431`),与"网络中途改变帧数"直接冲突——池化后 `get_num_frames()` 仍是旧 T,`RepMixer`/`MHSA`/`temporal_embedding` 的 `reshape(t_frames, …)` 全部错位。
- **正确落地顺序**:①先把帧数从全局单值改成**能逐阶段更新**(每次时序池化后 `set_num_frames(new_T)`,或让各时序算子从张量形状推断而非读全局);补 `test_t_agnostic.py` 式单测覆盖"阶段内变 T"。②再插入 strided 时序 conv/pool,做 8→4→2 调度。
- **价值不变**:唯一同时砍 55G FLOPs(深层最贵阶段少见帧)+ 减 stage-4 token 数(减轻 C1/峰值显存)的点。风险:过早池化冲淡短动作——在 MSR-VTT/DiDeMo 动作切片消融池化深度。
- **锚点**:X3D(CVPR'20)、MoViNet(CVPR'21)。

### C3'(重定位)· 因果时序卷积 + 流式缓冲 = 端侧**流式部署模式**(不再含弹性 T)
- **为何改**:草稿把"结构化消解硬编码 T"当卖点,但 §0 显示弹性 T **已完成**。去掉这条后,C3 的净增量是:因果 Conv1d + 每层 k−1 帧环形 buffer ⇒ **峰值激活显存与 T 无关的常数**、逐帧流式而非 8 帧批推。
- **成本/风险**:buffer 可作 stateful Core ML;因果只用过去帧,对"离线检索出一个 summary embedding"的场景收益有限——**定位成可选的流式部署形态,不是精度线**。MoViNet stream buffer 是端侧可导出直证。
- **锚点**:MoViNet stream buffers(CVPR'21);TSM 零 FLOP channel shift(ICCV'19)。

### C6'(重定位)· 文本塔 LoRA(导出期 merge)为主;温度只是松开 clamp
- **为何改**:`self.temp` 已是 Parameter、被 `clamp_(min=temp_min)`+配置钉住(`:90/166`);sigmoid 路径的 `logit_scale/logit_bias`(`:145-146`)可学且 **R1a 已用 `different_lr` 在训**。"让温度可学"要么是改 `temp_min` 配置的小事,要么已被 R1a 覆盖。
- **净新增价值**:给**冻结文本塔**加 rank-8 **LoRA**(或仅 bias),联合训练、**导出期 merge 进权重 ⇒ 推理零成本**,让文本几何略贴视频分布。与 P4 SigLIP 叠加=复利 near-free。**区别于 P8「文本塔瘦身」——这是廉价解冻,不是缩小。**
- **锚点**:LoRA(2021)、SigLIP2 可学 bias/温度。

*(C4/C5/C7/C8/C9 经核查无需改写,沿用头脑风暴稿定义;行号锚点见 §1 表。)*

## §3 明确的死路(两位独立判定一致 + 本轮核查未翻案)

- **Delta / skip-convolution 稀疏冗余计算**:理论上最诱人(直冲逐帧卷积主导),但需**动态输入相关稀疏**(gather/scatter+数据相关 mask),Core ML/TFLite 静态图**导不出或极差**,常见理论减 FLOPs 却 wall-clock 更慢、且与量化打架。**只适合服务器端 fast 变体,不投端侧。** 锚点:Skip-Convolutions(CVPR'21)、Eventful Transformers(ICCV'23)。
- **Mamba / SSM 时序混合器**替 stage-4:selective-scan 是 Core ML 自定义核噩梦、端侧不成熟。**部署跳过。** 要线性注意力宁可 plain linear/agent attention(ECCV'24);C3′ 的因果卷积拿 ~80% 流式收益且无导出痛。
- **文本条件化的视频池化**:检索 gallery 的视频 embedding **无 query 预计算**,视频侧任何文本条件化破坏协议 —— 排除。
- **CoCa 式 caption 解码头**:增自回归解码成本、与冻结文本塔冲突,端侧不值。
