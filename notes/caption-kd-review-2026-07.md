## 一、Qwen 特征搭车蒸馏 —— 裁决

### 结论三条

1. **原版 MobileViCLIP 没有蒸馏这一步**（核验 arXiv 2508.07312v1 原文）：损失只有
   `L_VTC = ½(L_V2T + L_T2V)` 纯 InfoNCE（可学温度 τ），无 VTM/MLM/MFM，全文不出现
   distill 一词；文本塔冻结（论文消融：省显存不掉点）；8×RTX3090、batch 64/卡、lr 1e-5、
   InternVid-10M-FLT、8 帧 256²。蒸馏只通过 **MobileCLIP-S0/S2 初始化间接进入**
   （那两个权重是 DataCompDR-1B 蒸馏强化数据训出来的），从不出现在它自己的损失里。
   我们复现配置 `vtc=1.0` 是忠实的；论文线加 KD 是对原版的真增量。
2. **Qwen 作 KD 主教师：否**。四条独立理由，任一条都足够：
   - **`vtc_kd` 不可算**：DataCompDR 式相似度矩阵 KL 需要教师端图文共享对齐空间；
     Qwen3-VL 全模型内**没有任何对比对齐空间**（逐点见下），手搓一个 Qwen 文本嵌入的
     反证是 LLM2CLIP（2411.04997）：LLM 原始嵌入对图像字幕**可分性差**，须经对比微调
     才能进 CLIP 管线（E5-V 2407.12580、VLM2Vec 2410.05160、UniME 2504.17432 同）。
   - **覆盖 25–30% 且是偏置桶**：重述只过 RECAPTION 桶；关系型 KD 信号活在 B×B 成对
     矩阵里，随机 25% 覆盖 → 仅 ~6% 成对信号；把覆盖片编进专门 batch 修密度 = KD 臂
     只见"原字幕差的片"，选择偏置。与 InternVideo2 特征混用更不可行（两空间无共享几何）。
   - **零发表先例**：2023–2026 检索无一篇"生成式 VLM 内部特征 → 对比式双塔学生"并报
     零样本检索收益（近例全是 MLLM→MLLM、或经字幕而非特征、或 CLIP 教师→检索学生）。
     这是研究赌注，不是工程捷径。
   - **省的算力不是瓶颈**：搭车只省 Qwen prefill ≈ 17 H100·h（占重述任务本身 3–10%）；
     而 InternVideo2-1B **全语料** 24M 片 pass ≈ 21 H100·h 计算（4×H100 实际 1–2 天，
     瓶颈是视频解码；8×V100 约 5–7 天）。教师 = InternVideo2-stage2 维持不变
     （stage2 损失 L_CON+L_MAC+L_MLM，1B 版 51.9 ZS MSR-VTT T2V R@1，核验 2403.15377）。
3. **白捡字节做一行门控消融：有条件的是**。生成式几何是否在对比式几何之外带增量，
   是文献空白里一个便宜可测的问题——值一行 U9 消融（设计见下），先过 CKA 门再建。

### Qwen3-VL-8B 架构事实（核验 HF config）

| 部件 | 规格 |
|---|---|
| 视觉塔 | 27 层、hidden **1152**、SigLIP2-SO400M 级 ~0.41B |
| Patch | 16×16，temporal_patch=2（8 帧→4 时间组），2×2 空间合并 |
| Merger 出口 | **4096**（进 LLM 维度）；DeepStack：ViT 层 8/16/24 注入 LLM 层 0/1/2 |
| LLM | 36 层、hidden 4096 |
| 池化/投影头 | **无**。没有任何训练过的对比头 |

视觉 token 数：@256² = 256/片；@448² = 784/片。三个可挂钩点的几何：视觉塔出口
（SigLIP 初始化的残余几何，但在生成目标下微调过、无文本塔陪练，退化程度未测）＞
merger 后（纯投影，无度量结构）＞ LLM 隐层（无对比目标 + massive-activation 离群维
主导原始余弦，2402.17762，必须逐维 z-score）。

**维护者直觉部分成立的一点**：VidVec（2602.08099）证明生成式 MLLM 中后段层
（VideoLLaMA3 的 24/28 层）在**专用压缩 prompt + `<emb>` token** 下零训练即得
52.1 R@1 MSR-VTT T2V——生成式模型内部确有对齐几何；但那是特定 prompt 诱出的，
我们的稠密中文描述 prompt 下是否存活**未经检验**。

### 追问（2026-07-27 晚）：教师能不能换 InternVideo3？——不能当 vtc_kd 教师

网上核验三个候选，全都**没有对比式图文共享空间**：

- **InternVideo3**（arXiv 2606.12195，2026-06）：副标题即定性——*Agentify Foundation
  Models with Multimodal Contextual Reasoning*。8B instruct **MLLM/视频智能体**
  （M²LA KV 压缩、SFT+规则 RL+在线蒸馏的分阶段训练），不是双塔对比模型 →
  vtc_kd 不可算，与 Qwen 同类否决（只少掉覆盖率那一条理由）。
- **InternVideo2.5**（2501.12386）：同为长上下文 chat MLLM，同判。
- **InternVideo-Next**（2512.01342，2025-12）：自监督、**明确不用视频-文本监督**
  ——没有文本侧，出不了教师相似度矩阵；其视觉几何可作 kd_geo 候选，
  与 `+geo(Qwen)` 同规则过 CKA 门，不另开行。

**结论**：vtc_kd 教师维持 **InternVideo2-stage2**——它是该家族**最后一代**保有真对比
视频-文本空间的模型。想要更强教师的正道不是换代际，而是**换尺寸/集成**：
InternVideo2-stage2-**6B**（同族空间，ZS MSR-VTT ~55.9 vs 1B 的 51.9）或 1B+6B
双教师集成（DataCompDR 正是双教师配方）；按 U7-1 既有决策法，在 100k 切片上
1B vs 6B 先试再定，checkpoint 下载条目届时补进 `CHECKPOINTS.md`。

### 证据梯队（蒸馏路线排序）

- **Tier A（对比教师→对比学生，大增益、有复现）**：DataCompDR/MobileCLIP
  （2311.17049：合成字幕单项 +7.4 IN / +27.5 Flickr，教师嵌入蒸馏在其上再 +2.4 IN；
  λ=0.75）；MobileCLIP2（2508.20691，KD 温度校准是关键消融）；CLIP-KD（2307.12732，
  **简单特征 MSE 胜过关系/梯度/对比各变体**）；TinyCLIP（2309.12314）。
- **Tier B（任意空间关系型 KD，机制成立、增益 ~1 点级）**：Tung-Mori（1907.09682，
  行归一化 Gram——教师空间无关，这是 Qwen 特征唯一可走的门）；AM-RADIO（2312.06709，
  跨目标多教师可行，但教师全是编码器非解码器）。
- **Tier D（本提案原型：生成式特征→对比学生）**：**空集**。
- 附警告：教师更强 ≠ 学生更好（2511.17886，CLIP-KD 增益不随教师质量单调）。

**战略含义**：MobileCLIP 消融里 caption 通道占大头（+7.4/+27.5），教师嵌入 KD 是
+2.4 的增量——**不要为后者危及前者**（重述任务在关键路径上）。

### 存储与抽取工程数字

| 存什么（fp16） | B/片 | @6M | @24M |
|---|---|---|---|
| pooled 4096-d | 8 KiB | 48 GiB | 192 GiB |
| **投影 1024-d（推荐）** | **2 KiB** | **12 GiB** | 48 GiB |
| per-frame 8×4096 | 64 KiB | 384 GiB | 1.5 TiB |
| 全视觉 token 图 @256²/@448² | 2–6 MiB | 12–36 TiB | **不可行** |

U7 既有预算 45 KB/片与 DataCompDR 实测（36–83 KB/样本）同带，健全。

抽取要点：prefill 隐层对 temperature 不敏感（**只在 sample-1 的 prefill 抽**，帧抖动
自洽）；用**单层 forward hook**（~60 MB）而非 `output_hidden_states=True`（37 层全存
≈2.2 GB/prefill）；只在视觉 token 位池化，**绝不含生成 token**；逐维 z-score 强制。
**硬约束：vLLM/SGLang 的 generate 路径不暴露逐层隐层**——若抓取迫使重述退回 HF
generate（5–20× 慢），搭车即负收益；届时改单独 prefill-only pass（~3.4× IV2 单片
成本，零耦合风险）。

### U9 新行最小设计（`+geo(Qwen)`，先过门再建）

- 钩子：LLM 层 30/36（VidVec 80–85% 深度类比）+ 视觉塔 mean-pool 1152-d 对照；
  masked-mean → z-score → L2 → PCA-1024（100k 片拟合）→ fp16。
- 损失：Tung-Mori 归一化 Gram Frobenius（**不用 KL**——任意空间教师无校准温度），
  λ_geo ∈ [0.1, 0.5]；batch 采样器把覆盖片编组保 B_kd。
- **CKA 前置门**（~1 GPU·h，2.5k 试点片，先跑）：建 Qwen/IV2/中文句嵌入三方
  片×片相似度矩阵——CKA(Qwen, IV2) > 0.8 → 冗余撤行；∈[0.4, 0.7] 且
  CKA(Qwen, 字幕文本) ≥ CKA(IV2, 字幕文本) → 互补，建行；层扫 {18, 24, 30, 36}+塔出口。

## 二、caption 方案替代检索 —— 裁决

### 头条：没有更优替代；现阶梯处于或略超发表最佳实践

被逐项确认的设计：**A′ 句切 ≤32 token**（CLIPS 2411.16828：实测最优输入 token 长度
**恰为 32**，子句采样胜整条，小模型被长文伤得更重——硬预算正是发表甜点）；
**A− best-of-N**（Panda-70M 2402.19479 系）;**多字幕轮抽消费**（LaCLIP 2305.20088
+8.2 IN@12M 同机制）；**融合降级**获视频原生新证（2401.06129：全语料重述 +3.8 R@1
MSR-VTT t2v，而 LLM 合并帧字幕仅 +0.3 边际——正是我们降级的图景）；**C_v 独立验真
无发表先例**（领先文献，按门控处理正确）；原字幕按桶去留、反幻觉 prompt、OCR
verbatim（CapsFusion/LoTLIP/Nguyen 混合证据支持）。zh 特定文献无反证（无人研究过
zh 对比训练的字幕改写）。

### 与发表证据相抵的三处（采纳修正，落 §0.7）

1. **消费全部 5 条重述的视图 ↔ 两条饱和**（MobileCLIP2 2508.20691：合成字幕单项
   +7.3 IN@12M，**2 条即饱和**，1 模型出 10 条 ≈ 2 模型出 5 条）→ N=5 只作
   选择/验真池，**训练消费 ≤2–3 条重述的视图**（A− top-3 已天然满足；A′/G1 臂补
   同等上限）。
2. **只做 25% 桶 ↔ 全语料证据**（2401.06129 在 InternVid 上全量重述 +3.8；Nguyen
   2307.10350：sub-100M 规模改写>过滤、检索 2×，128M 处即最优、1.28B 才衰减——24M
   深处改写红利区）。审计 93.6%"对但粗"的大多数正是增益所在 → **分层扩展预案**：
   KEEP 桶 N=2 低配增补、原字幕并列保留（D6 不变：RECAPTION 桶原字幕仍不回流），
   挂 G1 后决策。
3. **G1 只看检索 ↔ 检索升/分类降实录**（Meta 工业报告 Xray 2602.16918：合成视频
   字幕提检索、降分类）→ G1/G2 **加零样本动作分类守门指标** + **原生中文评测**
   （Youku-mPLUG 2306.04362 检索子集）与译测 MSR-VTT-zh 同报，双向一致才算过。

### 两条警告与一处自证无虞

- **冻结 MiniRBT 塔在全部文献中无成功先例**：LiT 原文明说锁文本塔不行
  （2111.07991）；LanguageBind（2310.01852）冻的是**已对比对齐**的 OpenCLIP 塔；
  Chinese-CLIP（2211.01335）两阶段后全解冻。冻结的**非对比**中文塔是文献之外的
  配置 → 0.4 的 LoRA 臂由"应急预案"升格为"**大概率需要**"；G1 失败先疑塔后疑字幕。
- 免费诊断补一件：**冻结塔散度**——250 片实测样本上算 MiniRBT 编码的片内视图两两
  余弦（3-gram Jaccard 多样 ≠ 冻结塔空间多样；后者才折算成梯度信号），与 D11-iii
  探针同族可并跑。
- **A− 打分器 zh 能力自证无虞**：`score_alignment.py` 已用
  `google/siglip2-so400m-patch16-384`（多语言 Gemma 词表，XM3600 zh 检索有效）——
  英文打分器静默乱选 top-3 的风险不存在；bundle 回来看 5 条重述分差区分度即闭环。

### 新门控臂候选：CaRe-DPO 式字幕器自我改进（2509.16560）

用已有产物自动造偏好对：chosen = top-of-5（zh 打分）∧ 验真过；rejected =
bottom-of-5 ∨ 验真败 → LoRA-DPO Qwen3-VL-8B（fp16 LoRA 8×V100 放得下）→ 用
DPO 后字幕器重产 RECAPTION 桶。零人工标注；把 A−/C_v 的逐样本过滤信号摊销成
字幕器改进。证据是间接的（MLLM 检索器管线，非双塔预训练）→ G2 式自适应种子门
（Δ = DPO 臂 − C_v，KILL/ADOPT 区）。旁证：MobileCLIP2 字幕器微调可传导 +0.8 学生
精度（Table 6）。
