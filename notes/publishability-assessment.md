# 发表可行性自评 · 顶会前 go/no-go 备忘

**日期:** 2026-07-23
**问题:** 目前模型优化程度够吗?有创新点吗?能发顶会吗?
**一句话结论:** 新颖性站得住(靠 C2),但**核心主张尚未经任何全量实验检验**——
现在是一个**强计划**,不是一篇成形的论文。发顶会**有机会、条件性 yes**。
战略层详见 [`paper-plan-zh.md`](paper-plan-zh.md);本文只做冷静的可行性核对。

## 0. 现实校准(先摆正,别被计划的乐观语气盖住)

到今天为止,全量 10M 的 H100 训练**一步都没跑**(`notes/live/from-server.md` 无回报)。
已落地的只有:

- ✅ B0 基线复现成功(MSR-VTT t2v R@1=**42.50**,对上论文,见 `experiments/README.md` §3.4);
- ✅ V100/10k 试点验证了**链路**(`experiments/pilot_10k_results.md`);
- ✅ 实验框架 + 组件开关 + 卫生修复就绪(PR #64 起)。

⇒ **C1–C4 没有任何一项拿到过「比基线好」的数字。** 所以「优化程度够不够」现在
**无法回答**——不是不够,是**还没优化出结果**。手里是「想法 + 验证过的管线 +
复现的基线」,离「有优化程度」还差**整个主实验**。

## 1. 创新点评估(评的是计划的新颖性)

| 贡献 | 新颖性 | 判断 |
|---|---|---|
| **C2 时间维弹性蒸馏** | **真·新** | 唯一撑得起「一篇论文而非一次移植」的点。教师只编码一次 T=16,学生随机 T∈{2,4,8,16} 对齐同一目标 ⇒ 单 checkpoint、帧数即部署旋钮。成败全押在:单个弹性 ckpt 能否在每个预算点 Pareto 压过固定 T。**未验证。** |
| **C1 视频数据强化(DR)** | 中 | 「图像侧 DR 无视频版」站得住,但单独看=把 MobileCLIP2 配方搬到视频,易被评 incremental;靠 C2 当挡箭牌。 |
| **C3 sigmoid 多正例 + 注意力池化** | 低 | 已知技术,只值一张消融表,非卖点。 |
| **C4 端侧延迟表** | 加分项 | 移动端真机延迟是硬通货,但 P9 标注**联合注意力可能导不出**=延迟表前置风险。 |

**结构判断:** 创新集中在 C2 一根柱子。C1 是「合理但增量」,C3 是「配料」。典型的
**单点创新 + 扎实工程**——成败取决于这根柱子撑不撑得住。

## 2. 能发顶会吗:必要条件清单(缺一即降级)

目标 CVPR 2027(约 2026-11 截稿)/ 备选 ICLR 2027。以下**全部兑现**才是顶会级:

- [ ] **C2 干净 Pareto 胜利**:同一弹性 ckpt 在 T=2/4/8/16 每点 ≥ 对应固定 T 基线(等 FLOPs)。**这就是论文本身**;只「打平」则故事塌一半。
- [ ] **C1 DR 兑现图像侧量级**(+2–5 点),否则主线收益压不过「增量」质疑。
- [ ] **端侧延迟表真能导出**(过 P9),对比 MobileViCLIP / InternVideo2-S/B / **TempMe(ICLR'25,已发表的直接对手)**。
- [ ] **R0 全量复现 MobileViCLIP 量级**(尚未在 H100 验证)。

**拉高天花板的杠杆:** 弹性模型低 T 端若明显掉点 → 触发 R4(P7 非对称帧编码)做
组合 Pareto 面,从「一个技巧」升级为「一套帧预算方法论」;CapRL 合成字幕 +
时序难负例(几乎免费)加厚消融。

## 3. 真实风险

- 领域不空:efficient video-text 有 TempMe、各类 token merging 在竞争;弹性推理的
  「新」必须靠**实测 Pareto 图**说话,讲故事挡不住。
- **全押在尚未运行的主实验上**,算力默认 4×H100;R0 复现、教师推理成本、导出
  任一环出问题都会连锁。
- C1+C3 单独**发不了顶会**——它们是 C2 的支撑而非主张。

## 4. 下一步(在此之前一切「够不够/发不发得了」都是纸上推演)

**在 H100 上把 R0→R1 跑起来,拿到第一批真数字**(`experiments/SETUP_B100.md` +
`ROADMAP.md` 第三线 3.2)。有了 R0 复现 + R1 组件方向,才谈得上评估优化程度。
